# v0.23 部署与赛事运行说明

核对日期：2026-11-04。官方入口：[API Guide](https://agentmemories.ai/api-guide)、[Documentation](https://agentmemories.ai/docs)。本文陈述可核验的配置和操作约束，最终受理及公榜资格由赛事方判断。

## 版本与模型

ChronoTrace Memory v0.23，Textual，修订 `source-local-extents-01.contract03`。公开仓库提供对应的完整服务代码及运行兼容性修复，与线上部署采用相同核心方法和接口；文件校验信息列于[版本记录](PROVENANCE.md)。仓库用于复现审核，赛事实际调用参赛者自行部署的接口。

Add/Search 使用 DashScope 原生 HTTP 接口的 `text-embedding-v4`，1024 维，文档和查询分别用 `document`、`query` 角色，向量 L2 归一化。服务没有生成式 Add LLM、Search planner 或 Answer LLM，不调用生成式模型；最终 Answer/Eval 由平台固定流程执行。早期离线研究的本地模型不属于此在线实例。

## 配置与容量

| 项目 | 记录 / 要求 |
|---|---|
| Python | 3.12，依赖按源码包 `requirements.txt` 固定 |
| 进程 | Uvicorn，1 worker，线程及存储锁处理并发 |
| 检索模式 | `AE_MODE=query_document_evidence` |
| 证据预算 | `AE_CONTEXT_CHARS=24000`；与 `top_k` 分别限制字符量和条目数 |
| embedding | 1024 维，批次上限 10；默认超时 60 秒、瞬态请求最多 3 次尝试 |
| 原 Full 配置 | Add 并发 16、Search 并发 16、`top_k=100` |
| 本地示例端口 | 18406；由独立运行环境配置 |
| 存储 | 实例独占可写绝对路径；预留原文、向量、派生历史、journal 与备份空间 |

在线运行的 embedding、主机、磁盘、带宽及运维费用由部署者承担。合成验收不证明任意 Full 规模的吞吐和时延；实际容量随记忆量、文本长度及供应方配额变化。

正式接口须公开可达 HTTPS，不在 URL 中放凭据。代理保持正文、JSON 及 HTTP 状态。官方说明单请求最长可运行 30 分钟，代理要容纳同步写入，不能提前返回成功。Health 无鉴权，Add/Search 保持私密鉴权。实际域名、TLS 和服务管理由部署者维护。

## 持久化与恢复

以 `AE_DATABASE=/ABS/PATH/memory.sqlite3` 为例：

| 文件 | 作用 |
|---|---|
| `memory.sqlite3` | 原文、分块、向量及请求身份 |
| `memory.sqlite3.envelopes.sqlite3` | 原始请求与完成回执，已有记录禁止更新/删除 |
| `memory.sqlite3.chronotrace.sqlite3` | 来源锚定的派生对象与查询投影，仅追加 |

通过一致快照或停写备份保存整组文件及可能的 journal/WAL，不只复制正在写入的单个主库。不同实例不共享数据库。完成回执在可检索写入和派生步骤成功后追加，不是后台排队收据。

恢复前核验实际文件哈希、原配置、数据目录和资源余量。先检查服务、供应方和请求错误；平台正常处理或进入 Answer/Eval 阶段时不重复重启健康服务。保留失败签名及操作回执，按平台允许的原任务检查点恢复，不另建评测、改变模型/评分/并发或删除数据掩盖失败。Full 受理后保持代码与行为稳定；特定修复和原代码身份分别记录。

## 数据与公开材料

服务只处理平台发送的消息、查询和选项，不注入提示，不把外部答案作为记忆返回，不按数据集身份读取预存金标。日志仅保留路径、状态、耗时和必要脱敏错误，不记录密钥、完整请求正文或供应方回显文本。

赛事数据及派生副本只用于当前评测，不用于训练、微调、产品分析、数据集重建或传播。限制访问，任务完成后 30 天内清理，延长保留需赛事方书面同意。清理包括主库、envelope、派生库、快照、备份和含内容日志；“原文不可变”不免除任务完成后的删除义务。本次文档更新不执行清理。

公开材料提供代码、依赖、接口、合成测试、版本校验及运行说明。真实凭据通过私密渠道提供。提交 Full 与公榜通过分别记录；完整任务成功后仍需资格校验和审核，结果以官方记录为准。
