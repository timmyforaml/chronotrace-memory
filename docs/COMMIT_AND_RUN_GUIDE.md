# 提交说明与运行指南

本次以 `feat: release ChronoTrace Memory v0.1.0` 首次提交“ChronoTrace Memory（时序溯源记忆）”，发布不可变原文与独立派生账本组成的双时间状态内核、离线Python API/CLI、合成示例、28项测试、来源审计和中文指南；系统区分实体属性、有效时间、记录时间、真实状态变更与显式更正，保留可追溯历史，当前版本需要调用方提供结构化事件，冻结288题实验未取得准确率增益。运行需Python 3.10+，Windows依次执行 `git clone https://github.com/timmyforaml/chronotrace-memory.git`、`cd chronotrace-memory`、`python -m venv .venv`、`.venv\Scripts\python -m pip install .`、`.venv\Scripts\python examples/demo.py`，再用 `.venv\Scripts\python -m unittest discover -s tests -v` 检查测试；运行 `.venv\Scripts\python -m chronotrace_memory --input examples/alice.json --entity Alice --attribute home_city --intent current --as-of 2026-08-01` 查询当前住地，将参数换为 `--intent past --as-of 2026-02-01` 查询使用事后更正的历史住地，再加 `--known-at 2026-03-01` 查询当时已知的历史，三者分别为Berlin、Lyon、Paris；追加 `--ledger data/derived.sqlite3` 可单独保存派生审计，原始JSON不会被修改。Linux/macOS把Python启动命令改为 `python3`、虚拟环境解释器改为 `.venv/bin/python`；程序不需要GPU、模型或API Key，安装后可离线运行，完整输入字段及限制见 [USER_GUIDE.md](USER_GUIDE.md)。
